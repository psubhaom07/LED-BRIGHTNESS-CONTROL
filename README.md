# LED Brightness Control via Arduino and PWM

An Arduino Uno R3 project demonstrating continuous analog voltage sensing and Pulse Width Modulation (PWM) duty cycle control to dynamically regulate LED brightness.

## Description
This project reads an analog voltage signal (`0V–5V`) generated by a 10 kΩ potentiometer using the ATmega328P 10-bit Analog-to-Digital Converter (`ADC 0–1023`). The value is scaled algorithmically to an 8-bit PWM duty cycle (`0–255`) on Digital Pin 9, modulating the LED's forward voltage and effective output intensity smoothly. Live telemetry data (ADC input, mapped PWM, and duty cycle percentage) is streamed to the Serial Monitor.
